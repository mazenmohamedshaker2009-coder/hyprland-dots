# Hyprland Dots

A minimal, personal Hyprland setup built for speed, simplicity and everyday use.

> These dots are made for **my personal workflow**.
> They are not intended to be a full-featured desktop replacement.

## Features

- Dynamic colors powered by Matugen
- Minimal Waybar
- No Control Center
- No System Tray
- No Application Launcher
- Dynamic wallpaper system
- Custom Bash scripts
- Blur everywhere
- Fastfetch theme
- Custom Wlogout
- Hyprlock
- Hypridle

## Installation

```bash
git clone https://github.com/mazenmohamedshaker2009-coder/hyprland-dots

cd hyprland-dots

chmod +x install.sh

./install.sh
```

---

## Notes

These dots intentionally **do not include**:

- Rofi
- Wofi
- Application launcher
- Control Center
- System Tray
- Extra Waybar modules

The setup is designed around my own workflow and keyboard-driven navigation.
